# GIFs de demonstração

Pasta reservada para GIFs dos sistemas MWX.

- Nome do arquivo: `<sistema>.gif` (por exemplo `ponto.gif`, `atendimento-recrutamento.gif`).
- Largura recomendada: 1240 px, mesma proporção das telas (1240 × 920).
- Tamanho máximo recomendado: 10 MB por arquivo.
- Para publicar, troque o caminho da imagem do sistema na seção **Demonstrações** do `README.md` e na página do sistema em `docs/bots/`.
