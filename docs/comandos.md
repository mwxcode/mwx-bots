# 📋 Todos os comandos

Comandos de configuração exigem permissão de administrador (ou o cargo admin definido no bot).

## 🛡️ Management
| Comando | Descrição |
|---|---|
| `/advertir` | Dá uma advertência com motivo (cargo ADV) |
| `/advertencias` | Lista as advertências de um membro |
| `/remover-advertencia` | Remove uma advertência |
| `/castigo` / `/remover-castigo` | Castiga por tempo ou tira o castigo |
| `/expulsar` / `/banir` / `/desbanir` | Expulsão e banimento com log |
| `/limpar` | Apaga mensagens em massa |
| `/cargo adicionar\|remover` | Dá ou tira cargo |
| `/apelido` | Muda o apelido de um membro |
| `/trancar` / `/destrancar` / `/modo-lento` | Controle do canal |
| `/anuncio` | Anúncio com prévia antes de publicar |
| `/painel-booster` | Painel de impulsos |
| `/usuario-info` / `/servidor-info` | Informações |
| `/registro …` | Painel, configuração, consulta e busca por ID |
| `/ausencia …` | Pedir, ver status, painel, lista e encerrar ausências |
| `/filtro palavra\|site\|ignorar` | Listas dos filtros |
| `/config-management …` | Configuração completa |
| `/setup-servidor` | Monta a estrutura do servidor com prévia |
| `/ajuda-management` | Ajuda |

## 🎫 Atendimento
| Comando | Descrição |
|---|---|
| `/config-ticket` | Configuração completa e envio dos painéis |
| `/config-recrutamento` | Canais e cargos do recrutamento |
| `/tickets-painel` | Publica o painel público |
| `/ticket-assumir` | Assume o ticket |
| `/ticket-adicionar` / `/ticket-remover` | Adiciona ou remove alguém |
| `/renomear` | Renomeia o ticket |
| `/ticket-fechar` | Fecha e gera o transcript |
| `/reiniciar-ticket` | Reinicia o bot (admin) |

## ⏱️ Bate-Ponto
| Comando | Descrição |
|---|---|
| `/config-ponto` | Configuração |
| `/painel-ponto` | Publica o painel |
| `/horas-ponto` | Horas por membro com planilha |
| `/ranking-ponto` | Ranking de horas |
| `/relatorio-ponto` | Relatório do período |
| `/historico-ponto` | Histórico de pontos |
| `/resetar-ponto` | Zera um período |
| `/reiniciar-ponto` | Reinicia o bot (admin) |

## 🌾 Farm
| Comando | Descrição |
|---|---|
| `/farm-setup` | Cria canais, permissões e painel |
| `/config-farm …` | Cargos, canais, materiais, TOP e painel |
| `/painelfarm` | Reenvia o painel |
| `/farm-planilha` | Planilha .xlsx do mês |

Funciona pelos botões do painel (Denunciar e Acompanhar) e pelos cards da staff.
